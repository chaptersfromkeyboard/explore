# CardPulse — Credit Card Payment Reminder (Google AI Studio Compatible)

This project is structured as a standard **Vite + React + TypeScript + Tailwind CSS** application compatible with **Google AI Studio Build Mode**.

## How to Import into Google AI Studio
1. Upload this project folder to a **GitHub repository** (or push via GitHub Desktop / web upload).
2. Open [Google AI Studio](https://aistudio.google.com/) and switch to **Build** mode.
3. Click the **`+` (Add files)** menu in the prompt bar and select **Import from GitHub**.
4. Select your repository to continue prompting, editing, and deploying directly inside Google AI Studio.

## Local Development
```bash
npm install
npm run dev
```
